## **Pseudo-classes**

Some HTML elements go through different states, depending on how the user interacts with them while visiting a website.

![HTML element hover and click states](https://www.codedex.io/images/css/bonus-article-pseudo-class-states.gif)

Some examples of different states are:

- When you're hovering above a link or button.
- A link turning into a different color after it is clicked and visited.
- The child elements of a parent element, whether it's the first child, last child, or one in between.

In CSS, we can use **pseudo-classes** to style an element when it's in a specific state such as being hovered or an odd-numbered item in a list. Unlike pseudoscience, pseudo-classes are a little more real!

When you interact with your browser, the elements may change their state depending on what you do. In order to style those states, we use the following CSS:

```css
selector:pseudo-class {
  /* styles go here */
}
```

Pseudo-classes start with a regular selector followed by a colon `:`, then the pseudo-class.

Let's take a look at some of the pseudo-classes that CSS has to offer.

###  **Links**

The `<a>` anchor element is used for links on a website. Some of the most common pseudo-classes are associated with links, including `:hover` and `:visited`.

Styles with the `:hover` pseudo-class only apply when the cursor is placed above the targeted element:

```css
a:hover {
  background-color: yellow;
  color: red;
}
```

>[!NOTE] 
>This can also be applied to the `<button>` element!

### **Inputs**

The `<input>` element can also be selected with the `:hover` pseudo-class:

```css
input:hover {
  background-color: green;
}
```

This renders something like the following:

![Hover state with pseudo-class styling](https://www.codedex.io/images/css/bonus-article-pseudo-class-hover.gif)

If our input type is a `checkbox` or `radio` button, we can also use the `:checked` pseudo-class:

```css
input:checked {
  outline: 2px solid blue;
}
```

**Note:** You could also write `input[type="checkbox"]:checked` or `input[type="radio"]:checked`.

This renders the following:

![Inputs with CSS pseudo-classstyling](https://www.codedex.io/images/css/bonus-article-pseudo-class-inputs.gif)

### **Child Elements**

Pseudo-classes also allow us to target specific child elements from a parent element. Let's explore a few of them with the following HTML:

```html
<ul>
  <li>Doc</li>
  <li>Sleepy</li>
  <li>Dopey</li>
  <li>Grumpy</li>
  <li>Happy</li>
  <li>Bashful</li>
  <li>Sneezy</li>
</ul>
```

The `:first-child` pseudo-class selects the first direct child of a parent element. For example:

```css
li:first-child {
  border: 2px solid purple;
}
```

![First child element styled with purple border](https://www.codedex.io/images/css/bonus-article-pseudo-class-first-child.png)

There is also a `:last-child` pseudo-class:

```css
li:last-child {
  border: 2px solid purple;
}
```

It works like `:first-child` but selects the last child.

![Last child element styled with purple border](https://www.codedex.io/images/css/bonus-article-pseudo-class-last-child.png)

Then, there's the `:nth-child()` pseudo-class. This one can be applied in a few different ways.

We could select by its numerical, 1-based position with something like `:nth-child(5)`:

![Fifth child element styled with purple border](https://www.codedex.io/images/css/bonus-article-pseudo-class-nth-child.png)

Additionally, we can select multiple child elements with the `nth-child()` pseudo-class by passing either `even` or `odd` in the parentheses. This will style all direct child elements with an even or odd numerical position:

```css
li:nth-child(odd) {
  border: 2px solid purple;
}
```

Something like the style above would render the following:

![Odd-numbered child elements styled with purple border](https://www.codedex.io/images/css/bonus-article-pseudo-class-multi-child.png)
