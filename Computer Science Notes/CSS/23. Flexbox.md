## **In the Flex**

### **Flexbox**

So far, we've practiced using `display` and `position` to control how content and media appear on a page.

However, the `display` and `position` properties were originally designed for document layout with flowing text, headings, paragraphs. They weren't designed for arranging interface elements like navbars, card grids, or sidebars..

This is where Flexbox comes in!

**Flexbox**, short for Flexible Box Layout, is a CSS layout system designed to make it easier to arrange and align elements on a page, both in one dimension (row or column) and with dynamic spacing. It's like a magic bento box that automatically arranges boxes the way you want. 🍱

It was first introduced as part of CSS in 2009 but wasn't widely adopted until 2012-2013.

### **Flex Container and Items**

Flexbox works with a **two-level structure**: a parent and its children.

- The **flex container** is the parent element. This is where most of the flexbox properties live.
- The **flex items** are the direct children of that container. They respond to the rules the container sets.

In HTML, you would structure a parent container (in this case, a `<div>`), and child elements, or items:

```html
<div class="card-row">          <!-- flex container -->
  <div class="card">1</div>    <!-- flex item -->
  <div class="card">2</div>    <!-- flex item -->
  <div class="card">3</div>    <!-- flex item -->
</div>
```

To enable Flexbox, you'll write a single line of CSS applied to the container:

```css
.card-row {
  display: flex;
}
```

That's it! The moment you do this, the children of `.card-row` become flex items and Flexbox rules apply.

##  **Directions**

### **Flexbox Axes**

Now that `display: flex` has been applied to the container, it's time to understand how it thinks! 🤔

Flexbox operates on two axes:

- The **main axis** is the direction flex items are laid out.
- The **cross axis** runs perpendicular to it.

![](https://firebasestorage.googleapis.com/v0/b/codedex-io.appspot.com/o/curriculum%2Fimages%2Fcss-chapter-5%2F5-03.png?alt=media&token=4d735a29-fb8e-41d9-b2e1-1349967ab93a)

Almost every Flexbox property targets one of these two axes. They shift depending on one property: `flex-direction`.

###  **flex-direction**

`flex-direction` sets which direction the main axis runs, determining where your flex items flow.

```css
.card-container {
  display: flex; /* enables flexbox */
  flex-direction: column;
}
```

This is what your page would look like:

![](https://firebasestorage.googleapis.com/v0/b/codedex-io.appspot.com/o/curriculum%2Fimages%2Fcss-chapter-5%2F5-04.png?alt=media&token=8d39b73a-6604-49fa-9336-ae153a889507)

`flex-direction` accepts four values:

- `row`: items flow left to right (this is the default)
- `row-reverse`: items flow right to left
- `column`: items flow top to bottom
- `column-reverse`: items flow bottom to top

![](https://firebasestorage.googleapis.com/v0/b/codedex-io.appspot.com/o/curriculum%2Fimages%2Fcss-chapter-5%2F5-05.png?alt=media&token=be95682b-8fc5-4dda-9bfb-ce7cd0eccd73)

When the main axis changes, everything else shifts with it!

For `flex-direction: row`:

- The main axis is horizontal (left → right).
- The cross axis is vertical (top → bottom).

For `flex-direction: column`:

- The main axis is vertical.
- The cross axis is horizontal.

###  **flex-wrap**

By default, flexbox keeps everything on one line, even if that means shrinking or overflowing. You can change this with `flex-wrap`.

You can use the following values to change this behavior:

- `nowrap`: all items stay on one line, shrinking if needed (default)
- `wrap`: items spill onto new lines when they run out of room
- `wrap-reverse`: same as wrap, but new lines appear above instead of below

![](https://firebasestorage.googleapis.com/v0/b/codedex-io.appspot.com/o/curriculum%2Fimages%2Fcss-chapter-5%2F5-06.png?alt=media&token=0e478936-7bec-406d-88b5-be30de3d8be9)

Above, `flex-wrap: wrap` is used to move the book covers into a new line since there's no space left in the container.

```css
.book-row {
  display: flex;
  flex-wrap: wrap; /* remove this and the books will shrink onto one line */
}
```

Note that the book covers in this example stay in the _same_ order that they are listed in the HTML file.
