So far the cards in our exercises have had a fixed width. But one of the most powerful things about flexbox is that items don't have to be fixed, and they can grow and shrink fluidly based on available space!

![](https://firebasestorage.googleapis.com/v0/b/codedex-io.appspot.com/o/curriculum%2Fimages%2Fcss-chapter-5%2F5-11.gif?alt=media&token=85416489-d37a-472a-b4a4-60101ebba91f)

This is controlled by three properties: `flex-grow`, `flex-shrink`, and `flex-basis`.

### **flex-basis**

flex-basis sets an item's starting size before any leftover space is distributed. Think of it as the item's "ideal" size:

```css
.card {
  flex-basis: 200px;
}
```

The code above makes sure that each card width will start at `200px`, and will grow or shrink from that size!

You can use any CSS unit: px, rem, %. The default value is auto, which means the item sizes itself based on its content.

### **flex-grow**

Once `flex-basis` is set, there may be leftover space in the container. `flex-grow` determines whether an item is _allowed_ to grow to fill that space, and by how much relative to its siblings.

```css
.card {
  flex-grow: 1;
}
```

- A value of 0 means the item will not grow (default)
- A value of 1 means the item will grow to fill available space
- If multiple items have `flex-grow: 1`, they share the leftover space equally
- If one item has `flex-grow: 2` and another has `flex-grow: 1`, the first gets twice as much of the extra space

###  **flex-shrink**

flex-shrink is the opposite! It controls whether items are allowed to shrink when there isn't enough space.

```css
.card {
  flex-shrink: 1;
}
```

- A value of 1 means the item can shrink if needed (default)
- A value of 0 means the item refuses to shrink and will overflow the container before getting smaller

### **flex shorthand**

These three properties are almost always written together using the `flex` shorthand:

```css
.card {
  flex: 1;
  /* shorthand for: flex-grow: 1, flex-shrink: 1, flex-basis: 0 */
}
```

Notice that when using the shorthand, flex-basis becomes 0. This means items start from zero width and grow from scratch to fill the container equally, rather than starting from their content size. This is usually exactly what you want, and it's why `flex: 1` is the value you'll reach for most often!

Here are a few common presets worth knowing:

- `flex: 1`: Grow and shrink equally, starting from 0
- `flex: auto`: Grow and shrink, starting from the item's natural size
- `flex: none`: Don't grow, don't shrink
