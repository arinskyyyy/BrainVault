###  **Arrays**

Welcome! In this chapter, we're going to learn to store multiple values in a single variable called an array.

![](https://i.imgur.com/WVloHi6.gif)

**Arrays** are variables that can hold multiple values:

```js
array = ["Leonardo", "Michaelangelo", "Donatello", "Raphael"];
```

They are created using square brackets `[` and `]`. And the elements inside are separated by `,` commas.

The elements used for our array can either be a mix of data types, or of a single data type. For example, the two arrays below are both valid:

```js
let lotteryNumbers = [13, 36, 45, 57, 67, 14];       // call us if you have these numbers!
const lettersAndNumbers = ["a", "b", "c", 1, 2, 3];
```

We can define arrays either with `let` or `const`.
