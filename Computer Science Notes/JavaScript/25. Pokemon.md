###  **Updating Properties**

For objects, we can change an existing property and assign a new value:

```js
const user = {
  username: "@emmachamberlain",
  location: "Los Angeles, CA",
  followers: 15725078,
  following: 3, 
  verified: false
};

user.verified = true;
user.location = "🌐";

console.log(user);
```

Here, the user got verified and updated their location.

The output would now look like:

```js
{
  username: '@emmachamberlain',
  location: '🌐',
  followers: 15725078,
  following: 3,
  verified: true
}
```

### **Adding New Properties**

Another thing we can do with dot notation is assign a brand new property to an existing object.

Take this `fruit` object for example:

```js
const fruit = {
  name: "apple",
  quantity: 10,
}

console.log(fruit);

// Output: {name: 'apple', quantity: 10}
```

We can create and assign a new property to it:

```js
fruit.organic = true;

console.log(fruit);

// Output: {name: 'apple', quantity: 10, organic: true}
```

### **Object Methods**

In addition to housing raw data values, objects can also store functions as values! Whoa... 🤯

A function that is inside an object is referred to as a **method**. Check out this `phone` object that features a `ringtone` property:

```js
const phone = {
  model: "iPhone 11 Pro Max",
  brand: "Apple",
  version: 11.6,
  owner: "John Appleseed",
  ringtone: function () {
    console.log("Ring, ring! Ring, ring! 📲")
  }
}

phone.ringtone();
// Output: Ring, ring! Ring, ring! 📲
```

The `ringtone` property is a method and you tell it by the use of the `function` keyword, with parentheses.

The syntax is a little weird (`function () {...}`). But that's ok; the method's name is the same as the property name!

However, you can store methods in objects another way:

```js
const phone = {
  model: "Android",
  brand: "Samsung",
  version: 16.1,
  owner: "Jane Doe",
  ringtone () {
    console.log("Ring, ring! Ring, ring! 📲")
  }
}

phone.ringtone();
// Output: Ring, ring! Ring, ring! 📲
```

Here, we are sort of combining the key:value pair into one statement for the `ringtone()` method. This is actually the syntax that most programmers use.

> [!NOTE]
> But remember, the `key`:`value` pair is still there. `ringtone` is the key and the method body `() { ... }` is the value.
