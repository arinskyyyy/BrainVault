### **Selecting HTML Elements**

It's time to get into the fun stuff about the DOM!

The `document` object comes with methods and properties we can use for selecting one or more HTML elements.

Two of the most commonly used methods are the following:

- `.getElementById()`
- `.getElementsByClassName()`

These methods accept strings as parameters, which represent an element that may exist in a connected HTML file.

For example:

```html
<div id="status-update" class="post">
  <p>Just landed from my plane trip! ✈️</p>
</div>

<div id="posted" class="post">
  <img src="https://cdn.pixabay.com/photo/2017/05/12/13/17/night-flight-2307018_640.jpg" alt="plane taking off from the runway" />
  <p>I'm about to take off!</p>
  <p> So excited! 😬</p>
</div>
```

### **.getElementsByClassName()**

We can select multiple elements if they share the same `class` attribute, using the `.getElementsByClassName()` method:

```js
console.log(document.getElementsByClassName("post"));
// Output: HTMLCollection(2) [div#status-update.post, div#posted.post, status-update: div#status-update.post, posted: div#posted.post]
```

Wait, what did this return? An `HTMLCollection`? This object is similar to an array. We can access an individual element from this object via indices:

```js
console.log(document.getElementsByClassName("class-example")[0]);
// Output: <div id="status-update" class="post"><p>Just landed from my plane trip! ✈️</p></div>
```

### **.getElementById()**

We can also select an element with a matching `id` attribute, using the `.getElementById()` method:

```js
console.log(document.getElementById("posted"));
/* Output:
<div id="posted" class="post">
  <p>I'm about to take off for my flight!</p>
  <p>So excited! 😬</p>
</div>
*/
```

Lastly, we can use a combination of these methods if it's possible!

For example, if we want to select the first `<p>` paragraph element from the second `<div>` (with an `id` of `"posted"`), one way to do it is with `.getElementById("posted")` followed by `.querySelector("p")`:

```js
document.getElementById("posted").querySelector("p");
// Output: <p>I'm about to take off!</p>
```

### **Updating HTML Elements**

Remember: some objects contain certain properties and methods. This includes the element objects returned by the `document` object methods!

Depending on the element we select, we can access its content with one of the following properties:

- `.innerText`
- `.src`

### **.innerText**

The `.innerText` property returns the rendered text inside of a selected element, including any newlines.

```js
console.log(document.getElementById("posted").innerText);
// Output: "I'm about to take off!\n\nSo excited! 😬"
```

We can also change the text of a selected element by assigning a new string value with the `.innerText` property:

```js
let newText = document.getElementById("posted").querySelector("p").innerText = "I'm about to take off! It's an early flight, so I'm ready to sleep! 😴"

console.log(newText);
// Output: I'm about to take off! It's an early flight, so I'm ready to sleep! 😴
```

### **.src**

If we're working with an `<img>` image element, then we can access its `src` attribute with... you guessed it! The `.src` property!

```js
console.log(document.querySelector("img").src);
// Output: 'https://cdn.pixabay.com/photo/2017/05/12/13/17/night-flight-2307018_640.jpg'
```
