### **Changing CSS Styles**

Not only can we use DOM methods to manipulate our HTML content, but we can also change our CSS styles!

When selecting an element, you can access its `.style` property.

```js
document.getElementById("posted").style;
```

From there you can use any of the common CSS properties you know and love. Here are a few common ones:

|CSS Property|DOM Property|
|---|---|
|`background-color`|`backgroundColor`|
|`border`|`border`|
|`border-radius`|`borderRadius`|
|`font-size`|`fontSize`|
|`margin`|`margin`|
|`padding`|`padding`|
|`text-align`|`textAlign`|

> [!IMPORTANT]
> In the DOM, multiword CSS properties are in **camelCase**.

You can change the element's styling all from within the JavaScript:

```js
document.getElementById("posted").style.textAlign = "center";
```
