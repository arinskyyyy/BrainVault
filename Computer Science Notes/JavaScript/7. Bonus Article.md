By this point in the course, you may have come across an **error** or two when running the code. Here are some common ones:

- `SyntaxError`: happens when invalid JavaScript code is present while the program is running.
- `ReferenceError`: happens when you try to use a variable that isn't defined.
- `TypeError`: happens when a data type is being misused during an operation.

If you haven't realized by now, working with and overcoming errors is an everyday thing for all developers. Knowing how to identify and tackle different kinds of errors is a part of being a great programmer. 💪

Let's explore these below!

### **SyntaxError**

One of the most common errors you'll come across is the `SyntaxError`. These kinds of errors all come from some mistake in the actual JavaScript code, such as a missing period or parenthesis.

```js
console.log("Hello, World! 🌍"
```

The code above will produce the following `SyntaxError`:

```js
console.log("Hello, World! 🌍"
                    ^^^^^^^^^^^^^^^^^^

SyntaxError: missing ) after argument list
```

The error message is pretty straightforward here; we are missing the closing parenthesis `)` in `console.log()`.

**Note:** Be aware, however, that error messages may not always be so straightforward and require some real detective work to trace back where the error(s) actually occurred.

To avoid a `SyntaxError`, it helps to write your code in an editor that highlights or underlines invalid code. This way, you're more likely to catch these errors before running your code!

### **ReferenceError**

Another common error you'll encounter is the `ReferenceError`.

Simply put, this kind of error occurs when you're trying to use a variable that hasn't been defined yet.

For example:

```js
let score = x + 2;

console.log(score);
```

The code above would result in the following:

```js
let score = x + 2;
                 ^

ReferenceError: x is not defined
```

We are getting a `ReferenceError` because we didn't define an `x` variable and so JavaScript doesn't know how to move forward.

To avoid a `ReferenceError`, make sure all variables were at least defined with `let` or `const` beforehand. Depending on the program you're using, you can use ctrl + f to search for a specific variable name.

### **TypeError**

While working with variables of various data types in JavaScript, you are likely to encounter the `TypeError`.

This is especially be the case when trying to change the value of a `const` constant variable:

```js
const meaningOfLife = 42;

meaningOfLife = 43;
```

Running the code above will log the following in the console:

```js
meaningOfLife = 43;
              ^

TypeError: Assignment to constant variable.
```

To avoid the `TypeError` related to the `const` keyword, do two things:

1. Make sure all of your variables are at least defined with `let` and `const`.
2. Only use `const` for variables you don't intend to change; use `let` for the ones that may change.
