### **What is JavaScript?**

Welcome to The Origins III: JavaScript! Things are about to get fun. ✨

The programming language we're learning is called **JavaScript** and it powers 97.5% of websites today.

HTML + CSS + JavaScript = core languages of the web.

HTML and CSS give a website structure and styling, but JavaScript makes it interactive and _come alive_. It lets us add basic functionality and dynamic behaviors to our web pages.

But how did it come to be?

<img src="https://i.imgur.com/tekmLsi.gif" height="250px" />
