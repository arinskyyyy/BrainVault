### **Changing CSS Styles**

Not only can we use DOM methods to manipulate our HTML content, but we can also change our CSS styles!

When selecting an element, you can access its `.style` property.

```js
document.getElementById("posted").style;
```

From there you can use any of the common CSS properties you know and love. Here are a few common ones:

|CSS Property|DOM Property|
|---|---|
|`background-color`|`backgroundColor`|
|`border`|`border`|
|`border-radius`|`borderRadius`|
|`font-size`|`fontSize`|
|`margin`|`margin`|
|`padding`|`padding`|
|`text-align`|`textAlign`|

> [!IMPORTANT]
> In the DOM, multiword CSS properties are in **camelCase**.

You can change the element's styling all from within the JavaScript:

```js
document.getElementById("posted").style.textAlign = "center";
```

### **Events**

Thus far, we've only changed our rendered HTML by changing the actual code and saving the file. But most sites are much niftier than that; you can interact with it to make changes happen on the spot. This could include:

- Clicking a button on the site.
- Hovering over something with the mouse.
- Filling out and submitting a form.
- Using one of the keys on your keyboard.

All of these are example of **events**.

While HTML is where the events may take place, JavaScript is where we set them up. This is done with a DOM method called `.addEventListener()`.

When you select an element, you can use `.addEventListener()` to run a function on that element if the user performs a specific action, such as clicking or hovering:

```js
let likeButton = document.getElementById("like-button");
let likeCount = document.getElementById("like-count");

let numberOfLikes = 0

likeButton.addEventListener("click", function() {
  numberOfLikes++;
  likeCount.innerText = numberOfLikes;
});
```

In the example above, we are using `.addEventListener()` to attach a `"click"` event to the selected `likeButton`. When clicked, a function updates the `.innerText` of the selected `likeCount` element and increments it by 1, via the `numberOfLikes` variable.
